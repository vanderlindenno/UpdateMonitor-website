Configure UpdateMonitor with an Intune app configuration policy

For IT admins: decide warnings and the storage overview for every device, and keep the app's buttons out of the way.

Updated 4 November 2026

UpdateMonitor keeps an app update history on every Android device, with warnings when an app gets new permissions or is installed outside the Play Store. On devices managed with Microsoft Intune you can set it up for everyone at once, with an app configuration policy (Android Enterprise managed configuration). Users then can't change what you decided.

What you can set

Set it up in Intune

  1. Add UpdateMonitor as a Managed Google Play app and assign it to your devices.
  2. Go to Apps › App configuration policies › Add › Managed devices.
  3. Platform Android Enterprise; profile type Fully Managed, Dedicated and Corporate-Owned Work Profile, or Personal Work Profile. Targeted app: UpdateMonitor.
  4. Under Configuration settings choose Use configuration designer, click Add and pick the settings you need – or choose Enter JSON data and paste the example below.
  5. Assign the policy to your device group.
{
  "kind": "androidenterprise#managedConfiguration",
  "productId": "app:app.updatemonitor.mobile",
  "managedProperty": [
    {
      "key": "warnings_enabled",
      "valueBool": true
    },
    {
      "key": "storage_overview",
      "valueBool": true
    },
    {
      "key": "license_key",
      "valueString": "UM1.…your license key…"
    },
    {
      "key": "hide_settings",
      "valueBool": true
    },
    {
      "key": "hide_website",
      "valueBool": true
    }
  ]
}

Leave out license_key, hide_settings and hide_website if you only want to set warnings and the storage overview. Menu names can differ a little between Intune versions; the settings appear in Intune from app version 1.3.0.

Try the policy on a pilot group first. Assign it to a few phones of each model before all devices, and check that warnings and hidden buttons work as intended. See Test first, then roll out.

What the user sees

  • A managed setting stays visible in Settings, greyed out under Managed by your organisation, so users know why they can't change it.
  • A change in Intune applies at once while the app is open, otherwise the next time it is opened. Remove the policy and the user's own choices come back.
  • With warnings turned on, Android 13 and later still asks the user once for permission to show notifications, right after the welcome screen.
  • Without a valid license key, Hide settings and Hide website button do nothing: the buttons stay, and Settings says why.

Hiding the settings also hides the Warnings and Storage overview switches. Set warnings_enabled yourself if you hide the settings – otherwise warnings stay off, which is the default.

About the license key

One license per organisation, with no end date: it doesn't expire. The key holds your organisation's name and is checked offline on the device – there is no license server and nothing is sent. UpdateMonitor and RebootMonitor each have their own key.

The price depends on the number of devices. Tell us your organisation's name and roughly how many devices you manage, and we'll reply with a quote and send the key once the license is arranged.

Frequently asked questions

Which settings can an administrator manage in UpdateMonitor?

Warnings (on or off), the storage overview (on or off), and, with a license key, hiding the settings button and the Visit website button. The settings are part of a normal Intune app configuration policy for Android Enterprise.

What is free and what needs a license key?

The app, the warnings setting and the storage overview setting are free. A license key is only needed to hide the settings button and the website button. A valid key also shows your organisation's name in the app's About screen.

Does a RebootMonitor license work in UpdateMonitor?

No. Each app has its own license key: UpdateMonitor keys start with UM1, RebootMonitor keys with RM1.

Does UpdateMonitor send anything to Intune or to us?

No. The app has no internet permission. It reads the policy that Android hands it and checks the license key offline on the device.

How do I get a license key, and what does it cost?

Use the contact form on the home page and tell us the name of your organisation and roughly how many devices you manage. The price depends on the number of devices and is given on request.
